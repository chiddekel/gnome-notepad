Detailed Description

ZlibDecompressor - Zlib decompressor.

ZlibDecompressor is an implementation of Converter that decompresses data compressed with zlib.

◆ property_file_info()

Glib::PropertyProxy_ReadOnly< Glib::RefPtr< FileInfo > > Gio::ZlibDecompressor::property_file_info ( ) const

A Gio::FileInfo containing the information found in the gzip header of the data stream processed.

This will be nullptr if the header was not yet fully processed, is not present at all, or the compressor’s Gio::ZlibDecompressor::property_format() property is not Gio::ZlibCompressorFormat::GZIP.
