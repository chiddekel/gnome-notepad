Untitled — Notepad

Everything you need. Nothing you don't.

Six things GNOME Notepad actually does — no bundled extras, no hidden settings menus.

Fast startup

Built natively in C++ with GTK4 — no bundled runtime, no splash screen. It opens as fast as you can click.

Multi-encoding text

UTF-8, UTF-8 BOM, UTF-16 LE/BE, and ANSI, with configurable CRLF, LF, or CR line endings.

Find & replace

Wraparound search that keeps going from the top of the document instead of stopping at the last match.

Two menus, one app

A GNOME-style hamburger menu, or a classic Win32-style menu bar — File, Edit, Format, View, Help. Your call.

Live language switching

Eleven interface languages, switchable from the menu with no restart required.

Light & dark, automatically

Follows your system theme by default, or force one from the View menu.

Simple by design

The full application window — nothing hidden behind a marketing crop.

Sometimes a text editor should just be a text editor.

GNOME Notepad exists because opening a text file shouldn't mean waiting on a bundled runtime or learning a new interface. It launches fast, edits plainly, and stays out of the way — the same idea classic Notepad had, rebuilt natively for the GNOME desktop.

Get GNOME Notepad

Install as a Flatpak from the project's self-hosted, GPG-signed repository — or build it from source.

Download latest release View source code
Platform: Linux, via Flatpak License: MIT
bash 
$ flatpak remote-add --user --if-not-exists notepad https://chiddekel.github.io/gnome-notepad/notepad.flatpakrepo
$ flatpak install --user notepad io.github.chiddekel.Notepad
